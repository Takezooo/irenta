iRenta is a comprehensive platform designed to simplify the management of rental properties. It enables users to search for accommodations, manage property listings, tenants, and payments seamlessly. Tenants can track their payments, request maintenance, and more, making the rental process efficient for both owners and seekers.

---

## 🚀 Features

### For Owners:
- Add, Edit, and Manage property listings.
- Track tenant information and manage payments.
- Receive and address maintenance requests from tenants.
- Create, Edit, and Manage Terms and Lease Agreements.
- Send Agreements
- etc.

### For Tenants:
- Search for available properties.
- Request Ocular Visit and Request Reservation
- Track Payment history and pending payments.
- Submit maintenance requests with detailed descriptions.
- etc.

---

## 🛠️ Technical Details
- **Frontend**: React.js
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Deployment**: Vercel & Railway
